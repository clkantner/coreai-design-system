# Support

## How to file issues and get help

This project uses [GitHub Issues](https://github.com/microsoft/coreai-design-system/issues) to track
bugs, feature requests, and usage questions. Search existing issues before filing a new issue to
avoid duplicates. When opening an issue, include the affected package or application, reproduction
steps, expected behavior, and relevant environment details.

Do not report security vulnerabilities through public GitHub issues. Follow the private reporting
instructions in [SECURITY.md](SECURITY.md).

## Microsoft Support Policy

Support for this project is limited to the community resources listed above. It is not covered by
Microsoft Customer Service and Support unless a separate support agreement explicitly states
otherwise.
